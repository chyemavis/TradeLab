Practice Portfolio

A browser-only React app: simulated prices, a portfolio saved in localStorage, and five animated term explanations.

How it works

One web page that runs entirely in your browser, with no server and no account. The screens are React components. A fixed file holds 8 sample stocks. A price simulator nudges prices every 3 seconds. Your cash and holdings are saved in localStorage, a small store the browser keeps for this site, so they survive closing the tab. Five small animations make the kernel.

localStorage

{cash, holdings:{SYM:{shares,avgCost}}, hasSeenIntro}. Survives reloads.

Run it & failure modes

Run

npm install → npm run dev → localhost:5173. Needs Node 18+ and no keys. Record in a phone-size window. Deployment is optional (Vercel), decided in 6-ship.

What can break
  • Corrupted save → start fresh at $10,000
  • Price ≤ 0 → minimum price floor
  • Bad trade or a share count ≤ 0 → inline error, Confirm disabled

Decisions

  • Yours: a browser-only React stack (JS over Python), simulated prices, run locally and record.
  • Derived: 8 stocks, a 3s tick, $10k start, the color tokens, the animation concepts.
  • Learning unknown: better AI design output comes from exact tokens and an avoid list instead of adjectives. Check each screen against the tokens during the build.
